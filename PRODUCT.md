# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Web enthusiasts, developers, retro OS fans, and creative users who want a rich, desktop-class operating system experience entirely inside a modern web browser.

## Product Purpose

BrowOS is an ultra-fast, visually impeccable web-based operating system inspired by modern macOS design principles. It provides a full window manager, virtual file system, terminal shell, native-grade creative tools (CodeBrow, BrowCut video editor), productivity apps, retro games, and peer-to-peer real-time connectivity.

## Positioning

Unlike toys or shallow static clones, BrowOS is a fully interactive, client-side operating system environment featuring real audio/video processing, a sandboxed virtual filesystem, custom shell, and serverless peer-to-peer WebRTC collaboration that runs anywhere without backend infrastructure.

## Operating Context

Runs in any modern desktop or mobile browser (Chrome, Safari, Firefox, Edge). Operates completely client-side with offline capability, utilizing localStorage/IndexedDB for persistence, Web Audio API, WebRTC, and Canvas/WebGL for rendering.

## Capabilities and Constraints

- Client-side WebRTC DataChannel networking for peer-to-peer file beam and multiplayer cursor co-presence.
- Virtual POSIX-like filesystem (`BrowFS`) backed by browser storage.
- Multi-window desktop with drag-and-drop, snapping, dock, menu bar, widgets, and Spaces.
- Must remain lightweight, fast-loading, zero-friction, and visually polished (macOS Sonoma/Sequoia frosted glass aesthetic).

## Brand Commitments

- Name: BrowOS
- Aesthetic: Modern Apple macOS frosted glass, San Francisco typography hierarchy, smooth cubic-bezier transitions, high contrast, tactile feedback, and delightful micro-interactions.
- Color: System accent `#0a84ff` (Apple blue), dark glass chrome with crisp 1px borders, subtle soft depth shadows.

## Product Principles

1. **Native-Grade Tactility:** Every interaction should feel snappy, responsive, and tactile with authentic feedback.
2. **Zero-Setup Serverless:** Leverage standard browser APIs (WebRTC, IndexedDB, Web Workers) so users can collaborate or transfer files instantly with zero accounts or backend servers.
3. **Craft Over Gimmicks:** Build deeply integrated, functional features with complete edge-case handling rather than superficial mockups.
